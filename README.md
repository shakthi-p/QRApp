## 📱 QRApp - Android QR Code Generator
QRApp is a simple Android application that allows users to generate QR codes from any website link. Just type or paste a URL (e.g., https://www.google.com), and the app will instantly generate a scannable QR code.

![QR Code Demo](https://user-images.githubusercontent.com/your-image-link-here.png)
![Generate QR](https://github.com/user-attachments/assets/f17f0393-310b-4090-bf82-1aee7616bcf9)

##  Features
Generate QR codes from any HTTPS link
Clean QR code output using ZXing library
Simple and user-friendly interface
Works offline after generation

## Built With
- **Java**
- **Android Studio**
- **ZXing** (for QR code encoding)
- **Gradle**

## Usage
1. Launch the app.
2. Enter a valid website URL (e.g., `https://www.amazon.in`).
3. Tap on "Generate QR Code".
4. A QR code will be displayed which you can scan using any QR scanner app.
